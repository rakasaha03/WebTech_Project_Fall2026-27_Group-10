CINEBOOK CUSTOMER MODULE

Open index.html to start.

Pages:
- Customer Login
- Customer Registration
- Movies
- Book Tickets

Demo customer login:
Email: customer@cinebook.demo
Password: Customer123

Customer registration fields:
- Full Name
- Email Address
- Phone Number
- Age
- Password
- Confirm Password

Booking:
- Select movie
- Select show date
- Select showtime
- Select ticket quantity (1 to 10)
- No seat selection

This is a simple front-end-only midterm module.
No database, LocalStorage, SessionStorage, or data arrays are used.
Registration checks the form and matching passwords but does not save a customer account.
Booking validates the ticket quantity and displays a confirmation message only.
No actual ticket, booking, or payment is stored.
Customer pages have their own CSS and JavaScript files and a teal/coral design distinct from the Admin module.
